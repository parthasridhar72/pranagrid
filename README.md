# PranaGrid: Federated National PHC Logistics & Health Supply Chain

Federated AI platform for India's Primary Healthcare Centre (PHC) network providing real-time visibility into medicine stocks, bed capacity, personnel attendance, predictive demand forecasting, emergency stock-out early warnings, cross-district redistribution, and privacy-preserving federated model training.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
